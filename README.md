# Intermission releases

Releases of **Intermission**, an app that pauses your music for a few minutes and brings it back on time. This
repository holds only release files; the app's code is not published here.

## Mac (direct download)

Download the latest `Intermission-<version>.dmg` from [Releases](https://github.com/elgenrbn/intermission-releases/releases),
open it and drag Intermission to Applications. It's signed with Developer ID and notarised by Apple. Works with the
Music app and Spotify. Requires macOS 15 or later.

## iPhone and iPad (AltStore PAL, EU)

Add this source in AltStore PAL:

```
https://elgenrbn.github.io/intermission-releases/source.json
```

The source's icon and screenshots are in this repository, and each version's Apple-notarised alternative
distribution package is in `releases/<version>/`, exactly as Apple delivers it.
